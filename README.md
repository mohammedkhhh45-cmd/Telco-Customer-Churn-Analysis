# Telco Customer Churn Analysis

## Overview
An Exploratory Data Analysis (EDA) and data cleaning workflow on the Telco Customer Churn dataset to uncover key factors influencing customer retention.

## Key Insights
* **Clean Records:** 7,032 rows analyzed after handling missing `TotalCharges` values.
* **Churn Rate:** ~26.58% (1,869 churned vs. 5,163 retained).
* **Tenure:** Churned customers average ~18.0 months compared to ~37.6 months for retained customers.
* **Monthly Charges:** Churned customers pay higher average monthly rates ($74.44/month vs. $61.31/month).
